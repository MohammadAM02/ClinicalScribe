# Security policy

## Reporting a vulnerability

Please do not open a public issue for a suspected security or privacy vulnerability.

Use GitHub's private vulnerability reporting for this repository when available. Otherwise, contact the maintainer privately through the GitHub profile and include:

- affected version or commit;
- reproduction steps;
- impact and data exposure;
- any suggested mitigation.

Please do not include real patient information, clinical transcripts, credentials, signing keys, or other sensitive data in reports.

## Privacy expectations

Clinical Scribe is intended to keep speech recognition on-device. Changes that add telemetry, transcript retention, network transmission, or third-party processing require explicit review and documentation.
